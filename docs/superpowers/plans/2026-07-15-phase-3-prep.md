### Task 1: WebViewService robustness — script timeout + web-content-process termination

**Files:**
- Modify: `MangaCarta/Services/WebViewService.swift` ONLY. Public surface unchanged.
- Test: none (live-behavior; existing suite is the regression gate)

**Requirements (from the Phase 2 final review's tracked findings):**
1. **`runScript` timeout.** Today the JS-eval continuation is the one unbounded wait in the pipeline: if `evaluateJavaScript` never calls back, the extract hangs holding the lock and every WebView source is wedged until relaunch. Add a deadline (15 s) mirroring `load()`'s pattern: on timeout, resume the script wait throwing `SourceError.extractionFailed("script timed out")`. The new dual-resolver (callback vs deadline) MUST funnel through a nil-check-and-clear single-resume guard like `resumeLoad`/`resumeChallenge` — no double-resume, no leak. Include the straggler `Task.isCancelled` guard after the swallowed sleep-cancellation (same bug class you fixed in the deadline tasks before).
2. **`webViewWebContentProcessDidTerminate`.** iOS reaps off-screen web content processes under memory pressure. Implement the delegate method: fail ALL pending waits (load, challenge, script) with `SourceError.navigationFailed("web content process terminated")`, clear `isChallengeActive` if set, and leave the service consistent so the NEXT extract reloads cleanly (WKWebView auto-recovers its process on the next load).

### Task 2: Switch sources from the Home screen

**Files:**
- Modify: `MangaCarta/Views/HomeView.swift`
- Modify: `MangaCarta/Views/SettingsView.swift` (About row only)
- Test: none (SwiftUI menu; existing suite is the regression gate)

**Requirements:**
1. Home gets a toolbar source switcher. In `HomeView`, add `@AppStorage("settings.showAdultSources") private var showAdultSources = false` (same key Settings uses), and inside the `NavigationStack`'s content add a toolbar item:

```swift
            .toolbar {
                ToolbarItem(placement: .topBarTrailing) {
                    Menu {
                        ForEach(registry.visibleSources(includeAdult: showAdultSources), id: \.id) { source in
                            Button {
                                registry.activeSourceID = source.id
                            } label: {
                                if source.id == registry.activeSourceID {
                                    Label(source.name, systemImage: "checkmark")
                                } else {
                                    Text(source.name)
                                }
                            }
                        }
                    } label: {
                        HStack(spacing: 4) {
                            Text(registry.active.name.uppercased())
                                .font(.inkMono(11, weight: .semibold))
                                .tracking(0.5)
                            Image(systemName: "chevron.up.chevron.down")
                                .font(.system(size: 9, weight: .semibold))
                        }
                        .foregroundStyle(Ink.seal)
                    }
                }
            }
```

Selecting a source re-sources Home automatically (the Phase 2 `.task(id: registry.activeSourceID)` machinery — do not duplicate any reload calls).
2. Settings About row: replace the hardcoded `aboutRow("Source", "MangaDex API")` with `aboutRow("Sources", registry.sources.map(\.name).joined(separator: " · "))` (closes a tracked Phase-1 minor).
